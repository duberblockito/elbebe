# Game Plan: Memoria Musical 🎵🎹

**Source Idea:** 3-5/ideas-3-5.md
**Original ID:** Idea #8

## Concept
Auditory Simon Says. Animals play instruments in a sequence, player repeats.

## Requirements
- **Level**: Sequence length.
- **Progress**: Max sequence reached.
- **Persistence**: High score.

## Assets
- [ ] Animal musicians (Cat/Piano, Dog/Drum, etc.)
- [ ] Musical sound samples
- [ ] UI for turn indication

## Development Steps
1. Create `/games/memoria-musical/`
2. Sequence generation logic
3. Playback and input state machine
4. Failure/Success feedback

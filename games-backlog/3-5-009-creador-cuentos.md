# Game Plan: Creador de Cuentos 📖✨

**Source Idea:** 3-5/ideas-3-5.md
**Original ID:** Idea #9

## Concept
Pick 3 elements (Character, Place, Object) to generate a simple visual story.

## Requirements
- **Level**: Combinations.
- **Progress**: Tales told.
- **Persistence**: Saved stories (optional).

## Assets
- [ ] Icons for Story Elements (Princess, Robot, Forest, Space, etc.)
- [ ] Pre-made story templates
- [ ] Narration (TTS or pre-recorded)

## Development Steps
1. Create `/games/creador-cuentos/`
2. Selection UI
3. Story assembly logic
4. Playback mode

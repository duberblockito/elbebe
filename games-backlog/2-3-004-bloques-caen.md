# Game Plan: Los Bloques Caen 🧱

**Source Idea:** 2-3/ideas-2-3.md
**Original ID:** Idea #4

## Concept
Catch falling shapes (triangle, circle, square) before they hit the ground.

## Requirements
- **Level**: Infinite falling.
- **Progress**: Count caught blocks.
- **Persistence**: High score (local).

## Assets
- [ ] Shape sprites (Triangle, Circle, Square)
- [ ] Explosion/Confetti particles
- [ ] Fun sounds

## Development Steps
1. Create `/games/bloques-caen/`
2. Falling logic with increasing speed (optional)
3. Touch detection on moving targets
4. Score counter

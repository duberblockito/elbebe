# Game Plan: Apila los Animales 🐘

**Source Idea:** 2-3/ideas-2-3.md
**Original ID:** Idea #5

## Concept
Stack animals to build a tower. Touch animal to add it to the stack.

## Requirements
- **Level**: Reach 5 animals.
- **Progress**: Tower height.
- **Persistence**: N/A.

## Assets

- [ ] Stack sound (Plop)
- [ ] Wobble animation

## Development Steps
1. Create `/games/apila-animales/`

3. Physics-lite (wobble effect)

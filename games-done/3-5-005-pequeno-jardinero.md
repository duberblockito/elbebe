# Game Plan: Pequeño Jardinero 🌻💧

**Source Idea:** 3-5/ideas-3-5.md
**Original ID:** Idea #5

## Concept
Care for a plant by watering, giving sun, and weeding until it blooms.

## Requirements
- **Level**: Plant types.
- **Progress**: Garden size.
- **Persistence**: Unlocked flowers.

## Assets
- [ ] Plant growth stages sprites
- [ ] Tools (Watering can, Sun icon, Trowel)
- [ ] Garden background

## Development Steps
1. Create `/games/pequeno-jardinero/`
2. Plant state machine (Thirsty, Pale, Weedy, Healthy)
3. Interaction logic for tools
4. Growth animation

# Game Plan: Burbujas Mágicas

**Source Idea:** 0-1/ideas-0-1.md
**Original ID:** Idea #1

## Concept
Floating colorful bubbles that explode with soft sound and animation when touched. Infinite gameplay.

## Requirements (from Game Design Rules)
- **Level**: Duration 20s - 5m? (Infinite for 0-1, maybe adapt to "sessions")
- **Progress**: Visual timer/bar (optional for 0-1 but good for tracking session)
- **Persistence**: Save session time/bubbles popped.

## Assets
- [ ] Bubbles sprites/CSS
- [ ] Pop sound
- [ ] Background gradient

## Development Steps
1. Create `/games/burbujas-magicas/`
2. Implement bubble float logic (Canvas/DOM)
3. Add touch events
4. Add visual/audio feedback
